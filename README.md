# Після титрів · Лабораторна №5

Повноцінний застосунок для обліку фільмів і серіалів. `frontend/` — окрема копія React-застосунку з лабораторної №4. `backend/` — REST API на Express з MongoDB. Колекція зберігається на сервері, тому доступна після перезавантаження і з інших браузерів, які відкривають той самий сервер.

## Локальний запуск

Потрібні Node.js 22 або новіший, npm і Docker з Compose. Команди запускаються з каталогу `lab5` у Bash. У PowerShell для копії конфігурації використовуй `Copy-Item backend/.env.example backend/.env`.

```sh
docker compose up -d
cp backend/.env.example backend/.env
npm --prefix backend ci
npm --prefix frontend ci
npm --prefix frontend run build
npm --prefix backend run seed
npm --prefix backend start
```
## Як працює API

| Метод і маршрут | Дія |
| --- | --- |
| `GET /api/library` | Завантажити записи й категорії |
| `POST /api/categories` | Створити категорію з поля `name` |
| `POST /api/entries` | Додати запис. Повертає `201` |
| `GET /api/entries/:id` | Отримати актуальний запис |
| `PUT /api/entries/:id` | Оновити запис, передавши поточне поле `revision` |
| `DELETE /api/entries/:id?revision=0` | Видалити запис. Передай його поточну версію. Повертає `204` |
| `PATCH /api/entries/:id/progress` | Додати один переглянутий епізод. Тіло запиту — `{"revision":0}` з поточною версією запису |
| `PATCH /api/entries/:id/tier` | Змінити рівень запису. Передай `tier` від S до E або порожній рядок і поточний `revision` |
| `GET /api/stats` | Підрахувати записи за статусами, середній бал та епізоди |
| `GET /api/suggestion?exclude=:id` | Випадково вибрати запланований запис, за потреби виключити попередній |
| `GET /api/tier-list/export` | Згенерувати файл PNG або JPEG за фільтрами тірліста |
| `GET /api/health` | Перевірити з’єднання з MongoDB |

Приклад створення через `POST /api/entries` з типом `application/json`.

```json
{
  "title": "Останній сеанс",
  "category": "tv",
  "status": "planned",
  "totalEpisodes": 8,
  "watchedEpisodes": 0
}
```

Шар маршрутів перевіряє вхідні дані й формує HTTP-відповіді. Сервіс застосовує правила прогресу і працює з переданими йому моделями. Унікальний індекс захищає назви категорій від дублів. Оновлення записує документ лише за збігу `revision`, тож зміни з двох вкладок не перезаписують одна одну. Останній епізод автоматично змінює статус на «Переглянуто». Значення для статистики підраховуються з колекції MongoDB. Помилки API мають форму `{"error":{"code":"…","message":"…"}}`.

### Сезони та експорт

`POST` і `PUT` для записів приймають необов’язковий масив `seasons`, наприклад `[{"totalEpisodes":8,"watchedEpisodes":3},{"totalEpisodes":6,"watchedEpisodes":0}]`. Номер сезону визначає позиція в масиві. Сервер підраховує загальний прогрес, а `PATCH /progress` зараховує епізод у першому незавершеному сезоні. Записи без сезонів зберігають наявний загальний прогрес. Якщо старий клієнт пропустить поле `seasons` під час `PUT`, список сезонів збережеться.

Маршрут експорту приймає `format=png|jpeg`, `category`, `status`, текст пошуку `q` і `sort=recent|score|title`. Наприклад, `/api/tier-list/export?category=animation&status=watched&format=png` повертає PNG для переглянутої анімації. UI та API використовують спільні правила пошуку й сортування. До зображення потрапляють назви, категорії, роки, оцінки та локальні постери. Записи із зовнішніми постерами експортуються текстовими картками. Експорт обмежений 96 записами на файл, для більшої колекції звузь фільтр.

На дошці тірліста перетягни картку за ручку до потрібного ряду, включно з «Без рівня». Якщо натиснути ручку, з’явиться список рівнів для вибору клавіатурою або дотиком. Після збереження картка переходить до вибраного рівня.

## Перевірка

```sh
npm --prefix backend test
CI=true npm --prefix frontend test -- --watchAll=false --runInBand
CI=true npm --prefix frontend run build
```

Інтеграційні тести створюють окрему тимчасову базу в локальній MongoDB. Для запуску в іншому тестовому середовищі її адресу можна задати через `MONGO_TEST_URI`.
